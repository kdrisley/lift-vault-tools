Enter your 1-rep max and this tool sets your training max (90% of it) and lays out the full 5/3/1 loading for all three main weeks plus the deload. Example loading for a 90 kg training max is shown below.

5/3/1 loading for a 90 kg training max
WeekSets (% of TM)Top set
Week 1 (5s)65% / 75% / 85%77.5 kg x5+
Week 2 (3s)70% / 80% / 90%80 kg x3+
Week 3 (5/3/1)75% / 85% / 95%85 kg x1+
Deload40% / 50% / 60%55 kg x5

The last set of each main week is an AMRAP, so you do as many reps as you can with good form. See the full 5/3/1 spreadsheets to run the whole program.
